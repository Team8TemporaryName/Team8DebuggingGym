# ADR-003: Generate Exercises With An LLM And A Deterministic Fallback

- **Status:** Accepted
- **Created:** 2026-10-24
- **Updated:** 2026-10-24
- **Containers:** `webapp`
- **Addresses:** [`FR-002`](../../functional-requirements/fr/FR-002.md), [`QR-02`](../../quality-requirements/qr/QR-02.md)
- **Decision:** [`DEC-009`](../../decisions.md#dec-009), [`DEC-010`](../../decisions.md#dec-010)

## Context

The product generates exercises for a chosen problem kind. The customer decided only instructors generate, and a learner's generated exercise is not stored or executed on the platform ([`DEC-010`](../../decisions.md#dec-010)). The API-key budget is small ([`CON-02`](../../product-vision.md#con-02)), so the product cannot depend on the LLM provider being available or affordable for every request, and the generator must stay testable from a clean checkout without a key ([`QR-02`](../../quality-requirements/qr/QR-02.md)).

## Considered Options

- **LLM generation with a deterministic local fallback.**
  Use the LLM provider when a key is set, and fall back to a curated deterministic generator otherwise. Generation always returns an exercise, and tests run without a key.
- **LLM-only generation.**
  Depends on the provider and the key budget; without a key the product cannot generate, and tests cannot run offline.
- **A hand-curated catalogue only, no generation.**
  Gives no on-demand generation; the customer's re-scope keeps generation for instructors but still wants generated exercises, so a catalogue alone is not enough.

## Decision Outcome

Chosen option: LLM generation when a key is set, with a deterministic local fallback otherwise.
This keeps generation always available, stays within the key budget ([`CON-02`](../../product-vision.md#con-02)), and lets the generator be tested from a clean checkout ([`QR-02`](../../quality-requirements/qr/QR-02.md)).

## Consequences

- **Testability:** the deterministic fallback means [`QR-02`](../../quality-requirements/qr/QR-02.md)'s clean-checkout tests run without an LLM key.
- **Cost:** generated exercises can be buggy or unsuitable to run, which is why a learner's generated exercise is not stored or executed on the platform, per [`DEC-010`](../../decisions.md#dec-010).
- **Cost:** LLM output is non-deterministic, so the gallery holds instructor-verified problems ([`FR-005`](../../functional-requirements/fr/FR-005.md)) rather than raw generation.
