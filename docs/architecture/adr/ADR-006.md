# ADR-006: Expose Quality Signals From The Web App Container

- **Status:** Accepted
- **Created:** 2026-11-07
- **Updated:** 2026-11-07
- **Containers:** `webapp`
- **Addresses:** [`FR-017`](../../functional-requirements/fr/FR-017.md), [`QR-05`](../../quality-requirements/qr/QR-05.md)
- **Decision:** [`DEC-023`](../../decisions.md#dec-023)

## Context

The product must expose its operating quality signals so an operator can diagnose a failed request in the core task. `QR-05` requires a per-request log point readable in the observability backend within five seconds and an `SLI` failure series with a P95 within one minute.

The `webapp` container handles every HTTP request, so it is the natural place to emit a per-request signal with the request identifier, route, and outcome labels the diagnosability test reads.

## Considered Options

- **Emit a structured log line and a metric per request from the `webapp`.** The web app sees every request, so one middleware can assign a `request_id`, time the request, and emit the per-request point and the histogram the `SLI` is computed from.
- **Instrument each container's signals separately.** This spreads the per-request signal across containers and makes the diagnosability test need to query several scopes, without adding value.

## Decision Outcome

Chosen option: the `webapp` emits a structured log line per request (carrying `request_id`, `route`, `outcome`, and `duration_ms`) and a request-duration histogram, exported to OpenObserve, off by default via `OBSERVABILITY_ENABLED`. This is `SLI-01`'s point and aggregate.

## Consequences

- **Diagnosability:** a failed request is traceable from its `request_id` to its route and outcome in the staging organization, satisfying `QR-05`.
- **Safety:** signals are emitted only when observability is enabled, so collection never breaks the product.
- **One query owner:** the `SLI`'s `**Query:**` in `docs/observability.md` is what the dashboard chart runs, so the page owns the query.
- **Privacy:** the `request_id` is an opaque random identifier, never derived from personal data.
