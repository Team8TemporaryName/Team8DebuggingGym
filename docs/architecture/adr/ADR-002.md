# ADR-002: Attach The Learner's VS Code Over The Debug Adapter Protocol

- **Status:** Accepted
- **Created:** 2026-10-24
- **Updated:** 2026-10-24
- **Containers:** `webapp`, `debug-runtime`
- **Addresses:** [`FR-004`](../../functional-requirements/fr/FR-004.md), [`QR-01`](../../quality-requirements/qr/QR-01.md)
- **Decision:** [`DEC-004`](../../decisions.md#dec-004), [`DEC-012`](../../decisions.md#dec-012)

## Context

A learner debugs the exercise in their own installed VS Code ([`DEC-004`](../../decisions.md#dec-004)), and the product should move toward a VS Code extension in future releases ([`DEC-012`](../../decisions.md#dec-012)). The learner must attach their editor to the hosted runtime within two minutes ([`QR-01`](../../quality-requirements/qr/QR-01.md)). The product runs each exercise in a `debug-runtime` container on the VM.

## Considered Options

- **Debug Adapter Protocol (DAP) via `debugpy` on the runtime.**
  VS Code speaks DAP natively, so an unmodified VS Code attaches to the `debug-runtime`'s `debugpy` server with a `launch.json`. Proven in the Week 2 prototype.
- **A browser-based debugger embedded in the webapp.**
  Would keep the learner in the browser, but the customer chose the learner's own IDE ([`DEC-004`](../../decisions.md#dec-004)), and a browser debugger gives a weaker experience.
- **A custom VS Code extension from the start.**
  The customer wants this direction eventually ([`DEC-012`](../../decisions.md#dec-012)), but the extension's testing functionality could not be finished in time for the MUP.

## Decision Outcome

Chosen option: the `debug-runtime` exposes a `debugpy` DAP server, and the `webapp` returns a `launch.json` the learner's own VS Code uses to attach.
This reuses the proven path and lets an unmodified VS Code attach ([`QR-01`](../../quality-requirements/qr/QR-01.md)); a VS Code extension that automates this is a future release ([`DEC-012`](../../decisions.md#dec-012)).

## Consequences

- **Interaction Capability:** attaching from the learner's own installed VS Code is the experience the customer chose, and the two-minute attach target of [`QR-01`](../../quality-requirements/qr/QR-01.md) is reachable because VS Code ships DAP support.
- **Cost:** the learner must copy a `launch.json` and start the runtime manually today; the `vscode-extension` container brings the flow into the editor and is the step toward the one-click extension the customer asked for ([`DEC-012`](../../decisions.md#dec-012)).
