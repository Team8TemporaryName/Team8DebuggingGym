# FR-015: Track Which Exercises A Student Has Completed

- **Status:** Active
- **Traces to:** [`US-019`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/90), [`DEC-023`](../../decisions.md#dec-023)
- **Containers:** `webapp`, `database`

## Behavior

The product shall record that a learner completed an exercise when their fix passes the harness.

The product shall show a completed marker next to an exercise the learner has already completed.

The product shall not duplicate a completion when the learner completes the same exercise again.

## Acceptance Criteria

### AC-01

Given a learner's fix passes the harness, when the verify request completes, then the product records the exercise as completed for that learner.

### AC-02

Given a learner views the exercise list, when an exercise is completed, then it shows a completed marker.

### AC-03

Given a learner completes the same exercise again, when the verify completes, then the completion record is not duplicated.
