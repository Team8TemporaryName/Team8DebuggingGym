# FR-001: Catalogue Of Problem Kinds

- **Status:** Active
- **Traces to:** [`US-02`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/21) (see a catalogue of problem kinds), [`DEC-010`](../../decisions.md#dec-010)
- **Containers:** `webapp`

## Behavior

When a learner opens the Debugging Gym, the product shall show a named, non-empty list of debugging problem kinds.

The product shall list each kind with a short summary a learner recognises from real debugging.

When a learner selects a kind, the product shall let them proceed to an exercise of that kind.

## Acceptance Criteria

### AC-01

Given the web app is running, when a learner opens it, then the catalogue of problem kinds is visible and non-empty.

### AC-02

Given a problem kind in the catalogue, when a learner selects it, then the product starts an exercise of that kind.

### AC-03

Given a problem kind in the catalogue, when a learner reads its entry, then its name and summary match the debugging skill it trains.
