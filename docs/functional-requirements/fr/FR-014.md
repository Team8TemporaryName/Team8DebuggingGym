# FR-014: Download The VS Code Extension From The Web App

- **Status:** Active
- **Traces to:** [`US-017`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/88), [`DEC-012`](../../decisions.md#dec-012)
- **Containers:** `webapp`, `vscode-extension`

## Behavior

The product shall offer a download for the VS Code extension from the web application page.

When a learner requests the download, the product shall serve the packaged extension file.

## Acceptance Criteria

### AC-01

Given a learner is on the web app, when they look for the extension, then they see a download link or button.

### AC-02

Given the learner requests the download, when the server serves the file, then the served file is the packaged VS Code extension.
