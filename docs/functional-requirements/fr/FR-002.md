# FR-002: Exercise Generation

- **Status:** Active
- **Traces to:** [`US-01`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/19) (choose a problem kind and get a generated exercise), [`DEC-010`](../../decisions.md#dec-010), [`DEC-011`](../../decisions.md#dec-011)
- **Containers:** `webapp`

## Behavior

When an instructor requests an exercise for a chosen problem kind, the product shall generate a self-contained exercise for that kind.

The product shall generate the exercise with the LLM provider when a key is set, and with a deterministic local fallback otherwise, so generation always returns an exercise.

The product shall not store or execute a learner-requested generated exercise on the platform; it only returns the code and harness to the learner.

## Acceptance Criteria

### AC-01

Given an instructor requests an exercise for a chosen kind, when the product generates it, then the learner receives a program with a planted defect and a harness for that kind.

### AC-02

Given generation is called with no LLM key, when the product generates an exercise, then it still returns a deterministic exercise for the chosen kind.

### AC-03

Given two exercises generated for the same kind, when they are generated separately, then they are not identical programs.

### AC-04

Given a learner requests a generated exercise, when the product returns it, then it is not stored on the platform and is not executed on the server.
