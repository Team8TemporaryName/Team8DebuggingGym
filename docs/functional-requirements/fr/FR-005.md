# FR-005: Curated Gallery Of Problems

- **Status:** Active
- **Traces to:** [`US-07`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/26) (browse a public gallery of community exercises), [`DEC-011`](../../decisions.md#dec-011)
- **Containers:** `webapp`, `database`

## Behavior

When a learner opens the gallery, the product shall show a list of instructor-curated problems with their problem kind and difficulty.

When a learner chooses a gallery exercise, the product shall open it in the same connect-and-verify flow as a generated one.

The product shall publish to the gallery only problems an instructor has verified, so a learner cannot run a malicious or unverified problem.

## Acceptance Criteria

### AC-01

Given the gallery, when a learner opens it, then a list of exercises with their problem kind and difficulty is visible.

### AC-02

Given a gallery exercise, when a learner chooses it, then it opens in the connect-and-verify flow.

### AC-03

Given a problem an instructor has not verified, when a learner opens the gallery, then the problem is not shown.

### AC-04

Given a gallery exercise, when a learner opens it, then it shows the instructor who curated it.
