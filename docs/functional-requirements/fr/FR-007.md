# FR-007: Display Exercise Information in the VS Code Sidebar

- **Status:** Active
- **Traces to:** [`US-009`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/62), [`DEC-015`](../../decisions.md#dec-015)
- **Containers:** `vscode-extension`

## Behavior

When a learner opens the Debugging Gym sidebar in VS Code, the extension shall display the current exercise's task instructions and available exercise actions.

When no exercise is active, the extension shall display a clear prompt explaining how to start an exercise instead of displaying stale exercise information.

## Acceptance Criteria

### AC-01

Given the learner has generated an exercise, when the learner opens the Debugging Gym sidebar, then the sidebar displays the task instructions associated with that exercise.

### AC-02

Given the learner has not generated an exercise, when the learner opens the Debugging Gym sidebar, then the sidebar displays a prompt to start an exercise and does not display details from a previous exercise.

### AC-03

Given an exercise is active, when the learner views the sidebar, then the learner can identify the actions available for that exercise without relying solely on transient notifications.
