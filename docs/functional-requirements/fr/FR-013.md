# FR-013: Teacher Generates And Stores An Exercise

- **Status:** Active
- **Traces to:** [`US-015`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/86), [`DEC-023`](../../decisions.md#dec-023)
- **Containers:** `webapp`, `database`

## Behavior

The product shall let a teacher generate an exercise from a prompt and store it with a name and a description.

The product shall require a name and a prompt, and reject a request that omits them.

A stored teacher exercise shall appear in the library that students browse.

## Acceptance Criteria

### AC-01

Given a teacher provides a prompt, a name, and a description, when they request generation, then the product stores an exercise with those details.

### AC-02

Given a request without a name or without a prompt, when the teacher submits, then the product rejects it with a clear error.

### AC-03

Given a teacher-stored exercise, when a student views the library, then the exercise appears with its name and description.
