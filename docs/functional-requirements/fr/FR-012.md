# FR-012: Separate Teacher And Student Interfaces

- **Status:** Active
- **Traces to:** [`US-014`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/85), [`DEC-023`](../../decisions.md#dec-023)
- **Containers:** `webapp`, `vscode-extension`

## Behavior

The product shall provide separate teacher and student interfaces in the web application and VS Code extension.

On both surfaces, the product shall let a user switch to the teacher interface by entering a valid teacher access key, and shall keep them in the teacher interface for the session.

The product shall keep a student in the student interface and refuse teacher-only actions.

## Acceptance Criteria

### AC-01

Given a user enters a valid teacher access key in the web application or VS Code extension, when they submit it, then that surface switches to the teacher view.

### AC-02

Given a user enters an invalid teacher access key, when they submit it, then they stay in the student view and see an error.

### AC-03

Given a user in the teacher view, when they attempt a teacher-only action, then the product allows it; when a user in the student view attempts the same action, the product refuses it.
