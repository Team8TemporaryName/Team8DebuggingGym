# FR-006: Solve An Exercise From The VS Code Extension

- **Status:** Active
- **Traces to:** [`US-03`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/22) (connect VS Code to the exercise environment), [`DEC-012`](../../decisions.md#dec-012)
- **Containers:** `vscode-extension`, `webapp`

## Behavior

When a learner uses the VS Code extension, the product shall offer the choose, generate, verify, and task flow inside the editor.

When a learner picks a problem kind in the extension, the product shall fetch the catalogue and generate an exercise for it.

When a learner verifies their fix in the extension, the product shall POST the current editor content to the harness and show the pass/fail verdict.

## Acceptance Criteria

### AC-01

Given the VS Code extension is installed, when a learner runs the choose-kind command, then the extension lists the problem kinds from the web app catalogue.

### AC-02

Given a chosen kind, when a learner generates an exercise, then the source is written to the workspace and the task is shown.

### AC-03

Given a learner's edited source, when they verify it, then the extension reports pass or fail from the web app's harness.

### AC-04

Given no web app is reachable, when a learner uses the extension, then the extension reports the connection error rather than failing silently.
