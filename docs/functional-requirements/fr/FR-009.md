# FR-009: Run the Learner-Editable Harness Locally

- **Status:** Active
- **Traces to:** [`US-011`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/64), [`DEC-017`](../../decisions.md#dec-017)
- **Containers:** `vscode-extension`

## Behavior

When an exercise is created in the learner's workspace, the product shall provide the learner-accessible harness as a local file alongside the exercise source.

The product shall allow the learner to edit and run the local harness independently of requesting official server-side verification.

The product shall provide a way for the learner to restore the local harness to the original version supplied with the exercise.

## Acceptance Criteria

### AC-01

Given an exercise is created, when the learner opens its workspace, then the supplied local harness is present as a file that the learner can inspect and edit.

### AC-02

Given the local harness and exercise source are present in the workspace, when the learner runs the harness using the documented local execution method, then the harness executes locally and displays its result.

### AC-03

Given the learner has modified the local harness, when the learner requests restoration, then the local harness is replaced with the original version supplied with the exercise.

### AC-04

Given the learner modifies or runs the local harness, when the learner requests official verification, then the official verdict is determined by the server-side verification tests described in FR-003.
