# FR-010: Open Multi-File Exercises in the Workspace

- **Status:** Active
- **Traces to:** [`US-03`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/22), [`DEC-014`](../../decisions.md#dec-014), [`DEC-015`](../../decisions.md#dec-015)
- **Containers:** `vscode-extension`, `webapp`

## Behavior

When an exercise contains multiple source files, the product shall create a working folder containing all the files required by that exercise.

The product shall preserve the relative paths of the exercise files when writing them into the learner's workspace.

When a learner requests official verification of a multi-file exercise, the product shall evaluate the complete exercise rather than only the currently active source file.

## Acceptance Criteria

### AC-01

Given an exercise contains multiple source files, when the learner creates the exercise through VS Code, then all source files are available in its working folder with their relative paths preserved.

### AC-02

Given a source file imports or otherwise depends on another file in the same exercise, when the learner runs the exercise from its working folder, then the dependency can be resolved without manually moving or copying files.

### AC-03

Given a learner requests official verification of a multi-file exercise, when the product evaluates the submission, then the evaluation uses all required exercise files rather than only the currently active file.
