# FR-003: Verify A Fix Against The Harness

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/23) (verify the fix against the harness), [`DEC-006`](../../decisions.md#dec-006)
- **Containers:** `webapp`, `debug-runtime`

## Behavior

When a learner submits a fix for an exercise, the product shall run the fix against the exercise's harness and report pass or fail.

The product shall run the harness in an isolated runtime so the learner's code cannot affect other sessions.

The product shall keep the harness fixed and non-modifiable by the learner.

## Acceptance Criteria

### AC-01

Given a learner's fix that removes the defect, when the product runs the harness, then it reports that the defect is gone.

### AC-02

Given a fix that does not fully remove the defect, when the product runs the harness, then it reports that the defect is present.

### AC-03

Given the learner attempts to modify the harness, when the product runs the fix, then the harness is unchanged and still reports the outcome against the original criteria.

### AC-04

Given a learner submits source, when the product runs it, then the run is isolated from other learners' runs and from the product's own data store.
