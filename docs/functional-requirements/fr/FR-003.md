# FR-003: Verify a Fix Against Server-Side Tests

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/23), [`DEC-016`](../../decisions.md#dec-016), [`DEC-017`](../../decisions.md#dec-017)
- **Containers:** `webapp`, `debug-runtime`

## Behavior

When a learner requests verification of a fix, the product shall evaluate the submitted source against the authoritative server-side verification tests for that exercise and return a pass/fail verdict.

The product shall keep the authoritative verification tests under server control and separate from the learner-editable local harness.

When the learner's source is evaluated, the product shall run it in an isolated runtime so that it cannot affect other sessions or the product's own data store.

## Acceptance Criteria

### AC-01

Given a learner's source removes the targeted defect, when the product evaluates it against the authoritative server-side tests, then the product reports a passing verdict.

### AC-02

Given a learner's source still contains the targeted defect, when the product evaluates it against the authoritative server-side tests, then the product reports a failing verdict.

### AC-03

Given a learner modifies the local harness so that it reports a passing result for incorrect source, when the learner requests official verification, then the server-side tests determine the official verdict independently of the modified local harness.

### AC-04

Given a learner submits source for verification, when the product executes it, then the execution is isolated from other learners' executions and from the product's own data store.
