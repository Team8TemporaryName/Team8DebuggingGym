# FR-018: Authenticate Student And Teacher Accounts

- **Status:** Active
- **Traces to:** [US-18](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/89), [DEC-023](../../decisions.md#dec-023)
- **Containers:** `webapp`

## Behavior

The product shall let a registered user authenticate with an account and shall associate the authenticated session with the user's role (student or teacher).

The product shall restrict teacher-only actions to authenticated teacher accounts and shall not grant teacher privileges to student accounts.

## Acceptance Criteria

### AC-01

Given a registered student or teacher account, when the user submits valid credentials, then the product authenticates the user and associates the session with the account's role.

### AC-02

Given invalid credentials, when the user attempts to log in, then the product rejects the attempt and does not create an authenticated session.

### AC-03

Given an authenticated student account, when the user attempts a teacher-only action, then the product refuses the action.

### AC-04

Given an authenticated teacher account, when the user opens the teacher interface, then the product permits teacher-only actions.
