# FR-011: Store Exercises On The Server And Browse Them

- **Status:** Active
- **Traces to:** [`US-013`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/84), [`US-016`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/87), [`DEC-014`](../../decisions.md#dec-014)
- **Containers:** `webapp`, `database`

## Behavior

The product shall persist every generated or teacher-curated exercise on the server with a stable identifier, independent of the learner's local state.

The product shall return a stored exercise (its program, harness, and task) by its identifier.

When a learner opens the app, the product shall list the exercises stored on the server so the learner can choose one to solve.

## Acceptance Criteria

### AC-01

Given an exercise is generated or created, when the server responds, then the exercise is stored with a stable identifier that a later request can retrieve.

### AC-02

Given a stored exercise, when the learner requests it by its identifier, then the server returns its program, harness, and task.

### AC-03

Given a learner opens the app, when they view the exercise list, then the list shows the exercises stored on the server, not the learner's local files.
