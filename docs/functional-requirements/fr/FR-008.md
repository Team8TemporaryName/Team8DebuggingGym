# FR-008: Display Color-Coded Verification Results

- **Status:** Active
- **Traces to:** [`US-04`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/23), [`DEC-015`](../../decisions.md#dec-015)
- **Containers:** `vscode-extension`

## Behavior

When the server returns a successful verification result, the extension shall display a visibly distinguishable success status and the verification output.

When the server returns an unsuccessful verification result, the extension shall display a visibly distinguishable failure status and the verification output.

The extension shall communicate pass/fail status using text as well as color.

## Acceptance Criteria

### AC-01

Given the server returns a passing verification result, when the extension displays the result, then the success status is presented using the designated success color and explicit passing text.

### AC-02

Given the server returns a failing verification result, when the extension displays the result, then the failure status is presented using the designated failure color and explicit failing text.

### AC-03

Given the server returns verification output, when the extension displays the result, then the returned output is visible to the learner alongside the corresponding verification status.

### AC-04

Given the learner cannot distinguish the designated status colors, when the extension displays a verification result, then the textual passing or failing status remains sufficient to identify the result.
