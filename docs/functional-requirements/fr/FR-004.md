# FR-004: Connect VS Code To The Runtime

- **Status:** Active
- **Traces to:** [`US-03`](https://github.com/Team8TemporaryName/Team8DebuggingGym/issues/22) (connect VS Code to the exercise environment), [`DEC-004`](../../decisions.md#dec-004), [`DEC-012`](../../decisions.md#dec-012)
- **Containers:** `webapp`, `debug-runtime`

## Behavior

When a learner starts an exercise, the product shall return a Debug Adapter Protocol configuration so the learner's own installed VS Code can attach to the exercise's debug runtime.

When the learner's VS Code attaches, the product shall let them set breakpoints and inspect the stack and variables of the running program.

When a session ends, the product shall release the debug runtime so it is not left running.

## Acceptance Criteria

### AC-01

Given a generated exercise, when a learner follows the connect instructions from their own VS Code, then the editor attaches to the debug runtime over the Debug Adapter Protocol.

### AC-02

Given an attached VS Code, when a learner sets a breakpoint and runs the program, then execution stops at the breakpoint and the stack and variables are visible.

### AC-03

Given a disconnect during a session, when the connection is lost, then the runtime is released and the learner can reconnect or restart cleanly.
