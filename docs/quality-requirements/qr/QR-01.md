# QR-01: Attach VS Code Within Two Minutes

The VS Code extension attaches the learner's editor to the exercise environment within two minutes of the learner starting an exercise.

- **Status:** Active
- **Characteristic:** Interaction Capability
- **Sub-characteristic:** Operability
- **Business importance:** High
- **Technical risk:** High

## Scenario

### Source

A learner who has just started an exercise in the Debugging Gym VS Code extension.

### Stimulus

The learner starts an exercise and the extension connects the learner's editor to the exercise's debug environment.

### Environment

The learner runs an unmodified VS Code on their own machine with the Python and Debug Adapter Protocol extensions, and the product runs on the single VM of [`CON-01`](../../product-vision.md#con-01).

### Artifact

The `vscode-extension` that drives the connect flow and the `debug-runtime` that exposes the Debug Adapter Protocol server.

### Response

The extension shall attach the learner's editor to the debug environment and report the environment as connected, with the exercise source loaded.

### Response Measure

On a learner's machine over a typical connection, the extension completes the attach and reports the environment connected within two minutes of the learner starting the exercise in at least 9 of 10 attempts. The measure covers the extension's own connect flow, not the time a learner spends reading instructions.
A learner who cannot attach reports it, and the product tells them the next step rather than leaving them stuck.

## Critical Modules

The connect flow lives in [`app/main.py`](../../../app/main.py) (the launch endpoint that returns the attach configuration) and in [`vscode-extension/src/extension.ts`](../../../vscode-extension/src/extension.ts) (the client that opens the flow in the learner's editor)
