# QR-03: Release A Runtime And Keep No Learner Code

A debug session that ends mid-run releases its runtime within one minute and keeps no learner code on the server.

- **Status:** Active
- **Characteristic:** Security
- **Sub-characteristic:** Resistance
- **Business importance:** High
- **Technical risk:** High

## Scenario

### Source

A testing session ends mid-run, whether the learner's code raised an exception (non-dangerous), consumed all of the runtime's resources (dangerous), or the learner disconnected before the runtime was torn down.

### Stimulus

The learner's VS Code disconnects, the session times out, or the learner's code behaves unexpectedly (an exception or resource exhaustion) while a `debug-runtime` container is running the learner's edited source.

### Environment

The product runs on the single VM of [`CON-01`](../../product-vision.md#con-01) under the API-key budget of [`CON-02`](../../product-vision.md#con-02), and a learner may have several runtimes over a day.

### Artifact

The `debug-runtime` container, the sandbox that caps its resources ([`DEC-016`](../../decisions.md#dec-016)), and the `webapp`'s session management that owns the runtime's lifecycle.

### Response

The product shall reclaim the runtime and delete the learner's uploaded source, so a later learner cannot read or run a previous learner's code, and an unexpected program shall not crash the server.

### Response Measure

Within one minute of a session ending — whether by an exception, resource exhaustion, or disconnect — the runtime is stopped and its filesystem is removed, and no learner source remains on the server; a fresh session starts from a clean runtime.
The reclaimed resource count matches the sessions that ended, and a run that exhausts resources is contained rather than taking down the product.

## Critical Modules

The session lifecycle and the source upload live in [`app/main.py`](../../../app/main.py) (the exercise and verify endpoints).
The acceptance of this requirement is a candidate for `QR-02`'s testability story.
