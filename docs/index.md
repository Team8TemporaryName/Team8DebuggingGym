# Debugging Gym

**Debugging Gym** is a site that generates debugging exercises for a chosen problem category using an LLM and lets users connect from VS Code and debug them as they would debug real code. A public gallery collects community exercises.

This is the documentation site for the Debugging Gym project, team 8 in the ITPD course.

## The product

A learner:

1. chooses a debugging problem kind (for example an off-by-one bug),
2. gets a generated exercise — a small program with one planted defect,
3. connects their own VS Code to a hosted debug environment,
4. finds and fixes the bug, and
5. verifies the fix against a harness that reports pass/fail.

The minimum usable product, built in Week 3, is a working slice that completes this core task end to end. See [Setup and run](setup.md) to run it from a clean checkout.
